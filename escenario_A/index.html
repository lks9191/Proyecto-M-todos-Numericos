Simulación de distribución de recursos desde plantas de origen hacia zonas urbanas mediante sistemas de ecuaciones lineales

¿Qué se simula aquí?
Se modela una ciudad con 3 plantas de origen (centros de acopio o refinerías) y 3 zonas de destino (Norte, Centro, Sur). Cada zona tiene una demanda mínima, y cada planta tiene una capacidad máxima. El sistema de ecuaciones lineales Ax = b representa las restricciones de flujo. Se resuelve con distintos métodos iterativos y directos para encontrar cuánto debe enviar cada planta a cada zona. También se simula el efecto de bloqueos de rutas sobre el abastecimiento.
